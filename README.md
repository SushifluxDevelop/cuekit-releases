# CueKit – Downloads

CueKit is a free Stream Deck alternative for OBS: phones, tablets and browsers become your button deck, the PC runs the service.
CueKit ist eine kostenlose Stream-Deck-Alternative für OBS: Handys, Tablets und Browser werden zu deinem Tastenfeld, der PC führt den Dienst aus.

This repository only hosts the installers and update files (no source code). / Dieses Repository enthält nur Installer und Update-Dateien (keinen Quellcode).
